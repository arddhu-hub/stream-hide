# Origin and authorship

Author and maintainer: **Arddhu**. **All custom implementation code was written
by OpenAI Codex under Arddhu's direction.** No AI service runs inside the plugin.

This project originated from Arddhu's request for a separate streaming-oriented
variant of [File Hider](https://github.com/eldritch-oliver/file-hider), by
**Oliver Akins** (now Eldritch Oliver), MIT licensed. File Hider is the original
inspiration and functional starting point and must remain credited.

The resulting local plugin, previously called Stream Mode, was implemented
separately using its own CSS rules and independent settings rather than copying
the upstream TypeScript implementation. Stream Hide continues that implementation.
It is not an official release of File Hider. The upstream MIT notice is retained
in third-party/File-Hider-MIT.txt for explicit provenance. Its author did not
write or endorse the custom Codex implementation.

Our original code is MIT licensed. Obsidian's community-directory rules impose
additional conditions on submissions classified as forks; the MIT license alone
does not establish directory eligibility. This project has not been submitted
and no approval or endorsement from the original author is claimed.
