# Contributing

Install Node.js 20 or newer. No npm dependencies are needed.

```sh
npm ci
npm run build
npm test
npm run check
```

Open an issue describing the problem before substantial changes. Include your OS,
Obsidian version, plugin version and a minimal reproduction using synthetic data.
Do not upload vault contents, private paths, library files or image collections.
Keep runtime code readable and preserve license and attribution notices.
Changes to explorer styling need manual checks with the default theme and custom
themes. Forks are permitted by the license; Obsidian directory admission is a
separate process governed by its current developer policies.

All custom code in the initial release was written by OpenAI Codex under Arddhu's
direction. Describe subsequent contributions accurately rather than attributing
other people's work to Codex. There is no runtime AI dependency.
